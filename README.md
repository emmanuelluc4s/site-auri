# AURI

Loja online de acessórios e eletrônicos — catálogo com checkout via WhatsApp e painel administrativo multi-usuário.

## Stack

React + Vite + TypeScript · Tailwind CSS + shadcn/ui · Framer Motion · Supabase (Postgres + Auth + Storage + Edge Functions) · Deploy na Vercel.
